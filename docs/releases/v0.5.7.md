# Pi-Vis v0.5.7

## Highlights

- Improved startup reliability when loading the user’s login-shell environment and locating Node.js, including bounded subprocess work and protection against descendant processes that keep capture pipes open.
- Improved cross-platform process cleanup and hardened Windows utility resolution.
- Added sanitized diagnostics for shell-environment and Node-discovery failures, making startup issues easier to investigate without logging captured environment values or command output.

## Fixes and polish

- Prevented concurrent cold activations from launching duplicate login-shell environment captures.
- Added output limits, timeout handling, process-tree cleanup, and retry behavior for bounded subprocess operations.
- Preserved workspace-correct Node version-manager shims while keeping discovery within a shared startup budget.
- Expanded regression coverage for startup hangs, output limits, process termination, login-environment fallback, and Node lookup.

## Upgrade notes

- No manual action required. Existing sessions and saved state continue to work normally.

## Assets

- macOS Apple Silicon ZIP for installer/auto-update
- macOS Apple Silicon DMG for manual install
