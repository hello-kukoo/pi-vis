# Pi-Vis v0.5.5

## Highlights

- Updated the bundled Pi runtime to 0.84.2, bringing updated provider integrations, model and tool handling, extension APIs, and runtime reliability improvements.
- Added safe Markdown rendering for extension-provided content, including bounded custom transformers and protected handling of links, images, code, and other rich content.
- Improved transcript rendering and streaming reattachment for long responses, tool activity, and extension output.
- Improved provider authentication flows and expanded support for Pi's current public SDK and TUI APIs.

## Fixes and polish

- Fixed tool-call and tool-result ordering when extensions record messages during an active tool batch.
- Fixed restoration of sessions with an unterminated JSONL tail.
- Fixed native Mistral streaming for indexed tool-call continuation chunks that omit an ID.
- Hardened renderer/main protocol validation, session lifecycle handling, and packaged-runtime verification.
- Added broader regression, render, and real-SDK coverage for the pinned runtime upgrade.

## Upgrade notes

- No manual action required. Existing sessions and saved state continue to work normally. Pi-Vis continues to bundle and manage its own pinned Pi runtime; it does not use a Pi installation from your machine.

## Assets

- macOS Apple Silicon ZIP for installer/auto-update
- macOS Apple Silicon DMG for manual install
